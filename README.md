# Программное средство сегментации клиентов методами кластерного анализа в целях персонализации лояльности

Курсовой проект, БГУИР, кафедра проектирования информационно-компьютерных систем, группа 314302.

## Архитектура

| Узел | Технологии | Назначение |
|---|---|---|
| Веб-клиент (`frontend`) | React 19.2, TypeScript 5.9, Vite 7.3, Tailwind CSS 3.4, Chart.js 4.5; nginx 1.28 | Интерфейс пользователя, TLS, обратный прокси `/api` |
| Сервер бизнес-логики (`backend_core`) | Python 3.12, FastAPI 0.128, SQLAlchemy 2.0, asyncpg | REST API (44 операции), роли, шифрование ПДн, аудит, резервное копирование |
| Интеллектуальный сервис (`ai_service`) | FastAPI, scikit-learn 1.8, SciPy 1.17, NumPy 2.4, pandas 3.0 | K-Means++, метод Уорда, DBSCAN, PCA, метрики качества |
| СУБД (`postgres`) | PostgreSQL 17.7 | 13 таблиц в 3НФ, только TLS-подключения |

Все соединения между узлами защищены TLS (собственный удостоверяющий центр выпускается при первом запуске
служебным контейнером `certgen`). Наружу опубликован только веб-интерфейс: `https://localhost:8443`
(адрес `http://localhost:3000` перенаправляет на HTTPS).

## Запуск в Windows 8 и выше (без среды разработки)

1. Установить и запустить Docker Desktop.
2. Запустить `start.bat`. Скрипт создаст файл `.env` со случайными ключами, соберет и запустит контейнеры,
   заполнит базу демонстрационными данными (только при первом запуске) и откроет браузер.
3. При первом открытии браузер предупредит о сертификате собственного УЦ; для доверия можно импортировать
   `ca.crt` (`docker compose exec backend_core cat /certs/ca.crt > ca.crt`) в хранилище «Доверенные корневые центры».
4. Остановка — `stop.bat` (данные сохраняются в томе `postgres_data`, резервные копии — в папке `backups`).


## Тестирование

```
python -m venv .venv && .venv\Scripts\pip install -r requirements-dev.txt
cd tests\unit_ai && ..\..\.venv\Scripts\python -m pytest            # модульные тесты ИИ-сервиса
cd tests\unit_backend && ..\..\.venv\Scripts\python -m pytest       # модульные тесты сервера
cd tests\integration && ..\..\.venv\Scripts\python -m pytest        # интеграционные тесты (стек должен быть запущен)
.venv\Scripts\ruff check .                                          # статический анализ
```

Интеграционные тесты перезаполняют базу демонстрационными данными и временно останавливают ИИ-сервис (проверка отказоустойчивости).

## Структура

```
ai_service/        интеллектуальный микросервис (app/services/clustering.py — алгоритмическое ядро)
backend_core/      сервер бизнес-логики (routers — REST API, services — бизнес-логика, models — ORM)
frontend/          клиентское приложение (pages — разделы, components — общие элементы)
docker/            Dockerfile, конфигурация nginx, схема БД init.sql, выпуск сертификатов
scripts/           генерация демонстрационных данных, создание .env
tests/             модульные, интеграционные тесты и замеры производительности
```
